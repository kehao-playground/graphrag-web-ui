# Explore (Phase 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Explore tab — server-paginated parquet table browsing (6 tables) and a WebGL knowledge graph colored by community, backed by DuckDB direct-parquet reads.

**Architecture:** New read-only path `domain registry → DuckDB adapter → service (stale check) → routes`, fully parallel to the query path (shares no cache, no graphrag imports). Frontend adds an ExplorePanel (Segmented 圖譜|資料表) to ProjectDetail; graph rendering is react-sigma + graphology with a pure, sigma-free graph builder for testability.

**Tech Stack:** FastAPI + duckdb 1.5.5 (backend), React 19 + antd 6 + TanStack Query + @react-sigma/core 5 + graphology 0.26 + @react-sigma/layout-forceatlas2 (frontend).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-19-graphrag-web-ui-design.md` §6.1 (artifacts endpoints, amended 2026-08-22), §7 (Explore tab), §13 (2026-08-22 probe). Read before starting.
- Layers: `domain/` pure (no I/O, no external imports); `services/` no FastAPI/HTTPException; `adapters/` own duckdb import; `api/` translate errors. Error contract `{"detail": zh-TW}`; internals stay in logs.
- graphrag imports remain ONLY in `adapters/graphrag_search.py` (this phase adds none — duckdb reads parquet directly).
- No DB schema changes, no new env vars in this phase.
- Conventional Commits, English comments; zh-TW only UI strings + API `detail` values.
- Backend deps: add `duckdb>=1.5.5` to `backend/pyproject.toml`. Frontend deps: `@react-sigma/core@^5.0.6 @react-sigma/layout-forceatlas2 graphology@^0.26.0 graphology-layout-forceatlas2@^0.10.1` (check `npm view @react-sigma/layout-forceatlas2 version` at install; peer of core 5.x).
- parquet schemas (probed, §13): entities(id,human_readable_id,title,type,text_unit_ids,frequency,degree,description — **no community column**); relationships(source/target are entity **titles**); communities(...,level,entity_ids,...); community_reports(15 cols incl. findings list[dict]); documents(text AND raw_data); text_units(text,n_tokens,document_id).
- Not-indexed → HTTP 409 「尚未建立索引,請先執行索引任務」(same as query path); unknown table/hrid → 404 「未知的資料表」/「找不到該筆資料」.
- Route registration order: `/artifacts/graph` BEFORE `/artifacts/{table}` (FastAPI matches in order; otherwise "graph" binds to {table}).
- Tests: backend pytest conventions (httpx AsyncClient, app fixture per existing conftest); frontend vitest RTL conventions (URL-routing fetch mocks, antd portals cleanup via `destroyAll`).
- Full fast suites green before each commit; slow tests (LLM cost) ONLY in Task 6.
