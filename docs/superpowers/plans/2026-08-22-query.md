# Query (Phase 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four-mode GraphRAG query (local/global/drift/basic) with a per-project DataFrame cache, in-process `graphrag.api` calls, self-parsed citations, SSE streaming, and per-user+per-project rate limiting.

**Architecture:** `graphrag.api` search functions are async and take DataFrames — an LRU cache keyed by (path, mtime, size) avoids re-reading parquet per query (budget `QUERY_CACHE_MB`, default 1 GiB; shared 2 Gi pod with indexing — spec §6.4 amended 2026-08-22). Answers embed `[Data: <Label> (ids)]` markers; the domain citation parser joins marker ids against context frames (probe-verified 2026-08-22: basic → `[Data: Sources (2)]`, context `{"sources": DataFrame[id, text]}`; streaming yields plain str chunks with NO context). Default path is streaming: SSE `chunk` events, then a terminal `citations` event parsed from the assembled text, then `done` with timings. Search/stream callables live in adapters (graphrag import rule); the service owns rate limiting, frame assembly, timings, and citation assembly.

**Tech Stack:** graphrag 3.1.0 `graphrag.api` + `graphrag.api.query` (in-process, no subprocess), pandas parquet, FastAPI SSE, React 19 + AntD 6 + native EventSource.

## Global Constraints

- graphrag pinned `==3.1.0`. All `graphrag` imports live in `adapters/` only (AGENTS.md); `domain/` pure; `services/` no FastAPI/HTTPException.
- New env vars (exact): `QUERY_CACHE_MB=1024`, `QUERY_RATE_LIMIT_PER_HOUR=30` — sync in config.py, .env.example, docker-compose.yml, helm values.yaml (queryCacheMb, queryRateLimitPerHour plain `value:`), api-deployment.yaml, AGENTS.md.
- Mode→tables map (spec §6.4): basic→{text_units}; local→{entities, communities, community_reports, text_units, relationships}; drift→{entities, communities, community_reports, text_units, relationships}; global→{entities, communities, community_reports}. covariates optional for local (skip loading; graphrag handles empty).
- graphrag facts (verified): search fns `async` returning `tuple[str | dict | list, str | list[DataFrame] | dict[str, DataFrame]]`; `*_streaming` are sync fns returning `AsyncGenerator[str, None]`; context captured via callbacks internally; `load_config(root)` loads workspace settings + `.env` (LLM key from workspace `.env`, never DB).
- Citation contract: `Citation = {label: str, ids: [int], entries: [{id: int, text: str}]}`. Parser is label-generic: regex `\[Data: ...(\(ids\))\]`, split multi-label groups on `;`, normalize label (lowercase, spaces→underscore, singular/plural fold) to a context frame key; missing frame/id → entry with `text: null` (never 500).
- Response contracts: POST `/api/projects/{id}/query` body `{method, query, response_type?}` → `{answer, context, citations, timings}` where `context` is `[{name, rows}]` frame summaries (NOT raw frames); `timings` = `{frames_ms, search_ms, citations_ms, total_ms}`. SSE stream: `event: chunk` (data = JSON string fragment), `event: citations` (data = `[Citation]`), `event: done` (data = `{timings}`); mid-stream failure → `event: error` (data = `{detail}`) then close. All errors `{"detail"}` shape on the POST path.
- Permissions: query = viewer+ (`Action.view_project`). Rate limit per (user, project): sliding 1h window, default 30 → 429 `{"detail": "查詢過於頻繁,請稍後再試"}` (service raises `QueryRateLimitedError`; in-memory dict, single pod).
- SSE auth: `?token=` access-token fallback identical to jobs logs (reuse/extract `_sse_user` from jobs_routes into a shared helper in `api/deps.py` or import from jobs_routes — one source, no copy).
- Comments/commits English; zh-TW only UI strings + API error details. `frontend/src/api/types.ts` mirrors backend shapes.
- Suites stay green: backend 134 (incl. 3 slow), frontend 21+.
- nginx: generic `/api` block already has `proxy_buffering off` + `proxy_read_timeout 3600s` (Phase 3) — query SSE rides it; Task 7 smoke proves incremental delivery.
- No audit rows for queries (spec §5 scope).

### Task 1: domain citation parser

**Files:** Create `backend/src/graphrag_ui/domain/citations.py`; Test `backend/tests/test_domain_citations.py`

**Interfaces (produces):**
- `MARKER_RE` compiled pattern for `\[Data: <groups>\]` where groups = `Label (id[, id...])); Label (ids...)`.

- `build_citations(text: str, frames: dict[str, "pd.DataFrame"]) -> list[dict]` — Citation dicts; frame lookup via `_frame_key(label, frames)`: label normalized (Sources→sources, Entities→entities, Relations→relationships, Reports→reports, Communities→communities, Text Units→text_units/units); text column = first of (`text`, `title`, `description`, `name`) present; id column `id` (int coercion); unresolved → `entries: []` but ids kept.

The adapter/service flattens DataFrames before calling. `build_citations(text, texts_by_key: dict[str, dict[int, str]])`.
